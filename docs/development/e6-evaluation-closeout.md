# 研究流程评测收尾范围

复核 E6 已有的 24 道任务和 48 份报告。比较两种历史 DeepSeek 流程在固定公开资料上的交付、要点覆盖、引用支持、耗时和 Token 用量。DABStep、Hybrid 恢复和 RFC 演示功能维持现有范围。

旧 RAG v2 的 0.875 来自 8 道可回答测试题的宏平均证据 Recall@5。完整题集为 20 道开发题和 10 道测试题，证据标注待人工复核。旧十题的 3/10 为运行完成，2/10 为离线交付条件通过。路由规则一致性和引用 ID 有效性应按各自口径引用。

项目经历可用表述：

> 完成固定公开语料上 24 道任务、两种研究流程的配对评测，记录执行状态、引用检查、延迟与 Token 开销。用结构化 Trace 追踪交付失败和引用问题，分析额外检查的质量收益与成本。

引用审核从两套流程各等概率抽 50 条结构化 Claim，再各抽 20 条交给人工独立审核。人工包只显示主张及其实际引用证据。额外排错样本单独记录。保留历史评分与审核记录，人工未填写时将一致率标为待审。

RAG 项目经历可用表述：

> 实现混合检索及可选 BGE 重排。对照开发题的正确交付和耗时后，演示采用混合检索。将命中段落扩展为有长度上限的章节片段，使 7 道普通可回答开发题的页面证据命中从 4/16 增至 6/16。
