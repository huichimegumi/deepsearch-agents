# 研究流程评测收尾范围

复核 E6 已有的 24 道任务和 48 份报告。比较两种历史 DeepSeek 流程在固定公开资料上的交付、要点覆盖、引用支持、耗时和 Token 用量。DABStep、Hybrid 恢复和 RFC 演示功能维持现有范围。

旧 RAG v2 的 0.875 来自 8 道可回答测试题的宏平均证据 Recall@5。完整题集为 20 道开发题和 10 道测试题，证据标注待人工复核。旧十题的 3/10 为运行完成，2/10 为离线交付条件通过。路由规则一致性和引用 ID 有效性应按各自口径引用。

项目经历可用表述：

> 完成固定公开语料上 24 道任务、两种研究流程的配对评测，记录执行状态、引用检查、延迟与 Token 开销。用结构化 Trace 追踪交付失败和引用问题，分析额外检查的质量收益与成本。

引用审核从两套流程各等概率抽 50 条结构化 Claim，再各抽 20 条交给人工独立审核。人工包只显示主张及其实际引用证据。额外排错样本单独记录。保留历史评分与审核记录，人工未填写时将一致率标为待审。

RAG 项目经历可用表述：

> 实现混合检索及可选 BGE 重排。对照开发题的正确交付和耗时后，演示采用混合检索。拆分向量与词法排序定位词法排序过度偏向常见词的问题，在 RFC 演示采用 BM25 融合并保留章节扩展，使 7 道普通可回答开发题的页面证据命中从 6/15 增至 15/15（去重），取齐标注出处从 3/7 增至 7/7。

相关指标见 [RFC BM25 与 Writer 对照](../../evals/rfc_demo/bm25.md)。

端到端评测可用表述：

> 建立 DeepResearch Bench 16 题 × 4 种配置的报告评测。单轮基线以 36.8 秒中位耗时获得 6.51/10，DeepAgents 两档耗时约为其 3.2–4.9 倍，得分为 5.85 和 5.30。定位零搜索和引用整篇扣发并复测清零。将高预算流程的归档网页证据交给单轮 Writer，在 15 道配对题上使内容评分从 5.31 升到 6.41，13 题高于原流程，帮助定位压缩、写作和交付环节的整体损失。

端到端内容分使用公开准则和 OSODT 模型评审，样本及复测限制见 [DRB 对照与交叉实验](drb-duckduckgo-15.md)。
