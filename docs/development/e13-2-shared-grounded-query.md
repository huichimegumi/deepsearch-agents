# E13-2：完整公开定义与共享 SQL 子任务执行

新增 app/research/grounded_query.py 的 query_sql，直接使用既有 SQLCandidate 和只读 MetricRelations，没有再增加模型中间语言。应用和后续冻结实验复用同一执行函数。默认研究工作流不切换，函数返回 sql_subtask_only，执行成功/非空不意味着完整任务答对。

## 公开输入

grounded_context 的 complete_definitions=True 读取 catalog 中全部公开定义，并验证显式依赖。最多 128 条、定义 12000 tokens、完整 payload 24000 tokens；超预算、重复 ID 或依赖缺失时拒绝，不默默丢弃。保留完整字段含义。旧模式继续保留，避免改写 E12 已冻结输入。

本地两题预检均可提供全部 56 条定义，总 payload 约 7500 tokens。表范围仍为 11 张中的 2 张，并明确 table_scope.complete=false；实际候选值也保持不完整标记。完整定义不等于完整数据库可见性，更不意味着所有公开公式已能预计算。SQL 可按公开定义计算尚未预计算的表达式，不能自行发明规则。

指令要求从原题及定义确定输出、条件、排序、数量和名称表示，在 SELECT 中完成投影/格式；禁止凭常识添加阈值、把原始测量替代派生指标、返回多余诊断列。没有从参考 SQL 生成模板或按题号修改条件。

## 执行与记录

每次必须创建新目录；最多两请求、80000 预留 tokens、2400 输出 tokens。只在实际执行错误或空结果时反馈一次；错误非空答案不重试。所有候选、结果、引擎反馈和 trace 写入私有目录；结构化输出失败与预算错误终止。结果原样保存，最终列投影和名称转换由模型提交的只读 SQL 在后端执行，没有参考驱动的结果修正器。

相关测试 18 项通过：覆盖完整定义及缺失依赖/超预算拒绝、名称格式、排除条件、并列排序、错误/空结果重试、错误非空结果停止、输出目录禁止恢复，以及前阶段严格评分和名称负例。模拟模型测试只验证执行协议，不代表真实模型成绩。下一阶段冻结一次 qwen-flash 小样本实验，严格门槛保持 2/2；未达标即停止扩展。

Actions 保持关闭；不使用 DeepSeek、GPU或新 benchmark。
