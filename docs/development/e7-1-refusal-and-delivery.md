# E7-1：限定拒答、部分回答与失败诊断

Writer 明确把检索范围和缺失信息放入 limitations；没有正面事实时 claims/facts 为空。正面断言继续强制引用，不自动剥离无引用声明。Writer 能看到实际操作记录，工具失败不能当成信息不存在。结果增加后端计算的 evidence_assessment，包含实际检索来源、成功/失败次数和已交付 Evidence 数；全部取证失败返回 source_error，不能伪装正常拒答。Gap.reason 改为受整体输出 token 上限控制的诊断字符串，避免无关的 400 字符边界令可用报告降级；其他 schema 错误仍失败，原评分阈值未改。

14 项相关离线测试通过，包含超长诊断、空取证正确限定拒答、工具故障不可计正常完成、无引用事实仍被拒绝、数值绑定和中断预算恢复。真实 DeepSeek 对六个自编开发场景运行 18 次请求，全部正常终止，预设 answerability 5/6 符合。冲突题期望 partial，模型给 insufficient_evidence，作为失败保留，没有执行后重写标签或追该题调提示。此处仅检查交付协议，语义质量留 E7-3 独立校准。没有运行冻结的 30 题；全程 CPU、无 Web 请求。
