# E11-1：公开公式后端展开，小型选择接口

新增 MetricRegistry，从公开 schema_notes 的 calculation_knowledge 数学片段解析有限 LaTeX 语法：text 标识符、frac、乘除、比较和条件表达式，再用 Python AST 白名单转换到 E10 的 Expression。没有 eval 或任意 SQL；不支持的函数、命令、符号、递归和跨表依赖不对单表选择接口开放。每项指标保留定义 ID、原文 SHA256，以及实际使用的依赖指标哈希。

对实际公开知识离线检查：21 项计算知识中 12 项数学片段可解析，9 项明确拒绝；其中只有 4 项指标可完整绑定到单表。解析成功不代表可执行，跨表和未知符号仍被排除。这是定义覆盖数，不是题目通过数。生成端完全不读取参考 SQL。

MetricSelection 只含标量选择字段：输出指标/字段 ID、最多四个筛选、排序、分组、分档及可选锚点。公式、SQL 和表达式 DAG 不由模型填写。分档阈值和标签仍需模型从问题/公开定义正确选择，后端不能证明业务解释正确。

实体相对查询先执行一个有来源的锚点查找，严格要求唯一；缺失或多义直接失败。后续同组筛选和指标比较使用实际锚点结果绑定，不通过硬改条件求非空。通配值依其已声明模式匹配，名称整理只允许使用提供的文本绑定。分组粒度、唯一别名、参数和只读执行继续由 E10 编译器检查。

验证：指标选择和 E10 编译器共 16 passed，覆盖多期间锚点歧义拒绝、实际同组比较、公式依赖展开、分档平均数、公开来源哈希、未绑定实体/任意公式拒绝和恶意公式不可执行。Ruff 检查及格式通过。没有模型、GPU 或新 benchmark 下载，Actions 保持关闭。
